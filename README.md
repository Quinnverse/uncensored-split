# 任务拆分器

粘贴一段任务 → 自动拆成步骤 → 分成两组 → 复制文本或 JSON 给 agent。

## 启用（3 步）

1. GitHub 新建公开仓库（或用已有仓库），把本 zip 里的文件全部放到 `main` 根目录。
2. Settings → Pages → Source 选 `main` / `root` → Save。
3. 等约 1 分钟，打开 `https://<用户名>.github.io/<仓库名>/` 就能用。

## 手机当 app 用

浏览器打开上面的网址 → 菜单「添加到主屏幕」。之后有独立图标、全屏运行；断网也能用（Service Worker 已缓存页面）。

## 说明

- 零依赖、零下载、零配置：不需要 API Key、不需要模型、不联网也能判定。
- 打开即输入，输入即出结果；没有任何开关、滑块或选项。
- 输入只存在本机浏览器（localStorage），刷新不丢，不会上传。
- 点色块或「复制」拿走某组；「复制 JSON」给 agent，字段为 `id / route / input`。
- 分组是给 agent 的路由建议：标为「需要专用模型」的步骤可能涉及系统权限、第三方程序或安全边界，执行前先确认你有授权。
